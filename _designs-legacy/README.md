# Legacy design documents

These documents predate the split between design documents and implementation plans. Many were written as the plan for one change and not revisited afterwards, so they can name classes that no longer exist and describe behaviour that has since changed. Check any claim here against the code before relying on it.

They are being consolidated into current design documents under [`_designs/`](../_designs), one area at a time ([#1290](https://github.com/hardwood-hq/hardwood/issues/1290)). [`_plans/DESIGN_DOC_CONSOLIDATION.md`](../_plans/DESIGN_DOC_CONSOLIDATION.md) lists which document each of these becomes part of, and which areas are done. A document leaves this directory in the PR that consolidates it.

Do not add documents here, and do not update these beyond keeping their links working. A change to behaviour one of them describes is a reason to consolidate its area.
